---

5. RANDOM CHARACTER FUNCTIONS

---

Example:
function getUppercase() {
return upperLetters[Math.floor(Math.random() * upperLetters.length)];
}

Explanation:

* Math.random() → random number deta hai (0 to 1)
* Math.floor() → round down karta hai
* result → random index
* string[index] → random letter
